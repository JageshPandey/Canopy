# Canopy
**Your files, beautifully mapped.**

Welcome to **Canopy**, a modern, sleek, and exceptionally fast directory mapping tool designed to give you a pristine overview of your file system directly inside beautiful HTML reports.

## Getting Started
1. **Install Canopy**: Run the included `Canopy-Setup-v1.0.1.exe` wizard to install Canopy on your computer.
2. **Launch**: Open Canopy from your Start Menu or Desktop. You'll be greeted by a gorgeous dark mist splash screen before entering the main interface.
3. **Map a Directory**: Drag and drop any folder into the app window, or click the "Choose Folder" button.
4. **View your Forest**: Canopy will instantly scan your files and automatically launch a beautiful, custom HTML report detailing everything inside that folder, complete with dynamic custom file icons and a smooth layout!

## Features
- **Lightning Fast**: Built on an optimized Electron and Node.js architecture for near-instant scanning.
- **Beautiful UI**: Glassmorphism, smooth animations, dynamic dark/light mode scrollbars, and vibrant folder/file icons.
- **Portable HTML Reports**: Share your generated HTML file tree reports with anyone; they require no internet or external dependencies to view.
